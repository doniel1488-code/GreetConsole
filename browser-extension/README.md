# GreetConsole Yandex Browser Extension

Браузерная панель для GreetConsole: журнал Minecraft в реальном времени и командная строка от имени текущего игрока.

## Требования

- GreetConsole Fabric Mod **1.3.0** или новее, Minecraft 1.21.8.
- Яндекс Браузер или другой совместимый Chromium-браузер с поддержкой Manifest V3.
- Мод должен быть запущен в игре. Расширение подключается к локальному адресу `127.0.0.1:38761`.

## Установка в Яндекс Браузер

1. Скачай архив **GreetConsole-Yandex-Extension-1.0.0.zip** из GitHub Releases и распакуй его в постоянную папку.
2. Открой `browser://extensions`.
3. Включи режим разработчика.
4. Нажми **Загрузить распакованное расширение** и выбери папку `browser-extension` из исходников или распакованную папку расширения из архива.
5. Запусти Minecraft с GreetConsole 1.3.0, затем открой значок расширения.

Яндекс Браузер может отключать расширения, установленные вне официальных каталогов. Для постоянной установки потребуется публикация расширения в магазине или установка через поддерживаемый Яндексом пакет CRX3. Для локальной разработки и проверки используй режим разработчика.

## Что умеет

- Журнал `logs/latest.log` в реальном времени (последние строки и новые записи).
- Поиск, фильтр TRACE / DEBUG / INFO / WARN / ERROR / FATAL, пауза, очистка, копирование и автопрокрутка.
- Отображение Minecraft legacy-цветов `&` / `§`, HEX `&#RRGGBB`, расширенного HEX и ANSI SGR RGB / 256.
- Командная строка: Enter отправляет команду через активный Minecraft-клиент.
- История последних команд: стрелки вверх/вниз.

## Безопасность соединения

Мод слушает только `127.0.0.1` и не принимает соединения из локальной сети или интернета. HTTP API разрешает запросы только с фиксированного origin этого расширения; при запуске игры выдаётся новый случайный токен. Команды отправляются штатным клиентским методом Minecraft. Мод не повышает права игрока и не обходит серверные ограничения.

Расширение запрашивает host permission только для `http://127.0.0.1:38761/*`, а не для всех сайтов.

## Совместимость

Manifest V3. Яндекс Браузер поддерживает расширения из каталогов Chrome и Opera, а также локальную установку через свои механизмы. Актуальная инструкция: https://browser.yandex.ru/help/ru/personalization/extension
