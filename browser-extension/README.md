# GreetConsole Yandex Browser Extension

Браузерная панель GreetConsole: журнал Minecraft в реальном времени, строка игрового чата и команд, а также встроенный симулятор ресторана «Вкусно — и точка».

## Требования

- GreetConsole Fabric Mod **1.3.4** или новее и Minecraft 1.21.8 — для консоли и отправки сообщений в игру.
- Яндекс Браузер или другой совместимый Chromium-браузер с поддержкой Manifest V3.
- Симулятор ресторана работает автономно, без запущенного Minecraft.

## Установка в Яндекс Браузер

1. Скачай архив **GreetConsole-Yandex-Extension-1.0.5.zip** из GitHub Releases и распакуй его в постоянную папку.
2. Открой `browser://extensions`.
3. Включи режим разработчика.
4. Нажми **Загрузить распакованное расширение** и выбери распакованную папку расширения.
5. Нажми значок GreetConsole. Откроется отдельное окно, которое можно растягивать за края и углы. Повторный клик по значку переключит фокус на уже открытое окно.

Для консоли запусти Minecraft с GreetConsole 1.3.4; симулятор ресторана доступен сразу, даже без запущенной игры.

Яндекс Браузер может отключать расширения, установленные вне официальных каталогов. Для постоянной установки потребуется публикация расширения в магазине или установка через поддерживаемый Яндексом пакет CRX3. Для локальной разработки и проверки используй режим разработчика.

## Что умеет

- Журнал `logs/latest.log` в реальном времени.
- Поиск, фильтр TRACE / DEBUG / INFO / WARN / ERROR / FATAL, пауза, очистка, копирование и автопрокрутка.
- Minecraft legacy-цвета `&` / `§`, HEX `&#RRGGBB`, расширенный HEX и ANSI SGR RGB / 256.
- Единая строка чата: обычный текст отправляется в игровой чат, текст с `/` выполняется как команда.
- История последних сообщений и команд: стрелки вверх/вниз.
- Отдельное окно расширения с изменяемыми размерами и адаптивной раскладкой.

## Симулятор ресторана

- Приём гостей и очередь до трёх заказов; улучшение кассы увеличивает вместимость.
- Пять позиций меню, несколько этапов приготовления и независимые таймеры — можно вести несколько блюд параллельно.
- Склад ингредиентов, закупки у поставщиков, касса, расходы, выручка и прибыль.
- Улучшения гриля и фритюрницы ускоряют приготовление.
- Цель смены — восемь гостей; после выполнения можно закрыть смену и получить премию.
- Таймеры обновляются прямо на месте, без полной перерисовки карточек каждую четверть секунды — кнопки готовки не должны терять клики во время отсчёта.
- Прогресс хранится локально в данных расширения. При закрытии или скрытии окна таймеры готовки ставятся на паузу.
- Это неофициальная фанатская мини-игра, она не связана с реальной сетью ресторанов.

## Безопасность соединения

Мод слушает только `127.0.0.1` и не принимает соединения из локальной сети или интернета. HTTP API проверяет точный origin, если браузер его передаёт. Для Chromium-сборок, которые опускают Origin при loopback fetch, используется отдельный заголовок-маркер; предварительные CORS-запросы всё равно проверяются по точному origin. При запуске игры выдаётся новый случайный токен. Команды отправляются штатным клиентским методом Minecraft. Мод не повышает права игрока и не обходит серверные ограничения.

Расширение запрашивает host permission только для `http://127.0.0.1:38761/*`, а не для всех сайтов.

## Совместимость

Manifest V3. Яндекс Браузер поддерживает расширения из каталогов Chrome и Opera, а также локальную установку через свои механизмы. Актуальная инструкция: https://browser.yandex.ru/help/ru/personalization/extension
