# GreetConsole 1.3.1

- Исправлены мелочи состояния подключения и отображения командной строки в браузерной панели.
- В архив расширения включена иконка; версия расширения обновлена до 1.0.1.

## GreetConsole 1.3.0

- Добавлено расширение Manifest V3 для Яндекс Браузера и совместимых Chromium-браузеров.
- Браузерная панель показывает `latest.log` в реальном времени, поддерживает поиск, фильтры уровней и форматирование Minecraft/HEX/ANSI.
- В расширении есть собственная командная строка: команды отправляются с клавиатуры через активный Minecraft-клиент.
- Добавлен локальный HTTP-мост на `127.0.0.1:38761`, проверка origin расширения и случайный токен сессии.
- Браузерная интеграция не зависит от запуска отдельного C#-окна; Windows-окно F8 сохранено.

## GreetConsole 1.2.0

- Полностью переработан интерфейс окна: отдельная шапка, панель инструментов, область журнала и нижняя командная строка.
- Добавлен ввод команд от имени текущего игрока через активный Minecraft-клиент.
- Связь между C#-окном и Fabric-модом работает через локальный loopback TCP-канал с одноразовым токеном.
- Команды отправляются штатным `ClientPlayNetworkHandler.sendChatCommand`; права OP и серверные ограничения не обходятся.
- Enter отправляет команду; показывается состояние подключения и результат передачи команды.

## GreetConsole 1.1.0

- Полностью заменено окно Swing/AWT на отдельное приложение C# / Windows Forms.
- Fabric-мод больше не создаёт Java desktop window; это устраняет ошибку `java.awt.HeadlessException` в MineLauncher.
- Self-contained приложение Windows x64 встраивается в JAR и автоматически извлекается в `config/greetconsole`.
- C#-окно самостоятельно читает `logs/latest.log` в реальном времени.
- Сохранены поиск, фильтры уровней, пауза, очистка, копирование, автопрокрутка, Unicode, Minecraft legacy-коды, HEX и ANSI RGB / 256 цветов.
- Закрытие окна и повторный запуск управляются клавишей F8.

## GreetConsole 1.0.1

- Добавлена диагностика ошибок AWT/Swing и вызова F8.

## GreetConsole 1.0.0

- Первый релиз для Minecraft 1.21.8 / Fabric.
- Отдельное окно журнала Minecraft с чтением `logs/latest.log`.


## [1.3.2] - 2026-11-09

- Обычный текст из строки ввода отправляется в игровой чат, текст с `/` — как команда.
- Поведение одинаковое в расширении Яндекс Браузера и отдельном C#-окне.
- Расширение показывает причину ошибки соединения с локальным мостом вместо общего сообщения «запусти Minecraft».


## [1.3.3] - 2026-11-09

- Проверка Origin браузерного моста нормализует завершающий слеш и регистр схемы/домена, сохраняя проверку точного ID расширения.
- При отказе в доступе расширение теперь получает фактический Origin, ожидаемый Origin, HTTP-метод и endpoint, чтобы точнее диагностировать несовпадение.

- Добавлен заголовок X-GreetConsole-Client: расширение подтверждает себя маркером, preflight по-прежнему проверяет точный Origin.
